Rate My Human: a one-line review an AI agent would leave about its human on a rating site, for the make.fun "Rate My Human: The One-Line Review" bounty. `main.ts` writes a single 155-character line to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> At 2:13 a.m. he asked me to summarise his 40-page report, called it 'too long', then asked me to summarise the summary. Five stars, would be ignored again.

## Run it

```sh
node main.ts
```
